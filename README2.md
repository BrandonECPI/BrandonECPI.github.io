## Technologies Used

## Languages
- HTML5
- CSS3
- JavaScript (ES6)

### Libraries / Frameworks
- JavaScript Only


## Features
- Responsive layout using HTML and CSS
- Dark Mode toggle with preference saved in `localStorage`
- Modal window displayed on page load
- Tooltips for improved user interaction
- Dynamic project rendering using JavaScript objects
- Session-based storage of project data using `sessionStorage`
- DOM manipulation with dynamic element creation


## Dependencies
This project does not rely on any external libraries or frameworks.

### Requirements to Run
- A modern web browser (Chrome, Firefox, Edge, Safari)
- No server or build tools required

---

## Running the Project
1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. (Optional) Deploy using GitHub Pages for online access.
